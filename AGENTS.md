# Agent instructions

- This repo is a small payments module written in TypeScript.
- Keep changes small and explain them in the pull request.
- Never read, print or commit `.env` or any secret.
- Record your verdict with Slipmark after every review:
  `npx slipmark@0.5.0 attest --by <you> --verdict pass --subject <file>`
- Run `npm test` before you record a passing verdict.
